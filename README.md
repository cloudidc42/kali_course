## เกี่ยวกับหลักสูตรนี้

หลักสูตรนี้ออกแบบมาสำหรับผู้ที่ต้องการเรียนรู้ **Penetration Testing** และ **Ethical Hacking** อย่างจริงจัง ตั้งแต่ผู้เริ่มต้นที่ไม่มีความรู้พื้นฐานเลย ไปจนถึงระดับมืออาชีพที่สามารถทำงานเป็น Security Researcher หรือ Penetration Tester ได้

### ระดับหลักสูตร
- **ระดับที่ 1-30**: Fundamentals (พื้นฐาน)
- **ระดับที่ 31-60**: Intermediate (ระดับกลาง)  
- **ระดับที่ 61-80**: Advanced (ระดับสูง)
- **ระดับที่ 81-100**: Professional/World-Class (ระดับมืออาชีพ/ระดับโลก)

### ข้อกำหนดเบื้องต้น
- คอมพิวเตอร์ที่รัน Kali Linux ได้ (RAM 8GB+, Storage 50GB+)
- ความตั้งใจที่จะเรียนรู้
- **สำคัญ**: ใช้เพื่อการศึกษาและ Ethical Hacking เท่านั้น

## ข้อความสำคัญด้านกฎหมายและจริยธรรม

> **คำเตือน**: เนื้อหาในหลักสูตรนี้มีไว้เพื่อการศึกษาและ **Ethical Hacking** เท่านั้น  
> การนำไปใช้โจมตีระบบโดยไม่ได้รับอนุญาตเป็นสิ่งผิดกฎหมายในทุกประเทศ  
> ผู้เรียนต้องรับผิดชอบต่อการกระทำของตนเองทั้งหมด

### กฎทอง 3 ข้อ
1. **ได้รับอนุญาตเสมอ** - ทดสอบเฉพาะระบบที่ได้รับอนุญาตเป็นลายลักษณ์อักษร
2. **ไม่ทำลาย** - Penetration Tester ที่ดีไม่ทำลายระบบ
3. **รายงานผล** - แจ้งช่องโหว่ที่พบให้เจ้าของระบบทราบ
